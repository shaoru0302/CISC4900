# Kaggle Orders Dataset (jewelry.csv)

Purpose:
- Optional dataset for order history / analytics demo (SQL queries, reporting)

What it contains:
- Order datetime, Order ID, Purchased product ID, Quantity, Category alias, Price, etc.

How to get it:
1) Download from Kaggle (zip)
2) Extract jewelry.csv locally (raw file is not included in this repo by default)

How we plan to use it:
- Import into PostgreSQL as an "order_items_raw" table for analytics or demo order history.
